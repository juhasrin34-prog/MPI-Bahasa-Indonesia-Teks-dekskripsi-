Media Pembelajaran Interaktif (MPI) - Teks Deskripsi
===================================================

Struktur Modul Lengkap:
1. Apersepsi (Pengenalan & Stimulus Panca Indra)
2. Asesmen Awal (Diagnostic Assessment)
3. Materi Pokok (Pengertian, Ciri, Struktur, & Kaidah Kebahasaan)
4. Simulasi Interaktif ("Rakit Teks Deskripsimu")
5. Kuis Interaktif (Latihan Cepat & Feedback Immediate)
6. Asesmen Akhir (Summative Assessment)
7. Refleksi Pembelajaran (Evaluasi Perasaan & Pemahaman Siswa)

Cara Menggunakan:
-----------------
1. Ekstrak (unzip) file 'MPI_Teks_Deskripsi.zip'.
2. Buka folder hasil ekstrak.
3. Klik 2x pada file 'index.html' untuk membuaknya di Browser (Chrome, Edge, Firefox, dll.).
4. MPI siap digunakan secara daring maupun luring (offline) tanpa instalasi aplikasi tambahan!
